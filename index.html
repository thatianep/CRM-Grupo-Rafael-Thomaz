Integração com Google Planilhas

100% Grátis: agendamentos e cadastros enviados à sua planilha

Como funciona a sincronização?

Cole o código abaixo no Apps Script da sua planilha Google para receber os registros em tempo real. 

// Código completo e comentado em: google-apps-script/Code.gs
// (arquivo incluído no repositório do GitHub)
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var isMei = data.hasOwnProperty('documentoIdentidade') ||
              data.hasOwnProperty('atividades');
  var nomeAba = isMei ? 'Prestação de Serviços' : 'Agendamentos';
  var sheet = ss.getSheetByName(nomeAba) || ss.insertSheet(nomeAba);
  sheet.appendRow([
    data.nome || data.cliente || '', data.cnpj || data.documentoIdentidade || '',
    data.telefone || data.telefonePessoal || '', data.whatsapp || '',
    data.dataReuniao || '', data.horario || '',
    data.motivo || data.atividades || '', data.responsavel || 'Sistema',
    data.status || 'Cadastrado', new Date()
  ]);
  return ContentService.createTextOutput(JSON.stringify({"result":"success"})).setMimeType(ContentService.MimeType.JSON);
}

Integração com Office 365 (Excel Online / SharePoint)

Agendamentos e cadastros enviados automaticamente para sua planilha do Microsoft 365

Como funciona a sincronização?

A Microsoft não permite gravar direto numa planilha Excel a partir do navegador com segurança (exigiria expor uma senha da sua conta no código). O caminho oficial e seguro é usar o Power Automate (incluso no seu plano Microsoft 365), criando um fluxo que recebe os dados e grava automaticamente numa tabela do Excel salva no OneDrive ou SharePoint.

1 Crie o fluxo no Power Automate

  1. Acesse make.powerautomate.com com sua conta Microsoft 365 da empresa.
  2. Crie um fluxo "Automatizado" com o gatilho "Quando uma solicitação HTTP for recebida" (When a HTTP request is received).
  3. Deixe o corpo da solicitação (Request Body JSON Schema) vazio por enquanto — o Power Automate preenche sozinho depois do primeiro envio de teste.
  4. Crie (ou use) uma planilha Excel com uma Tabela (Inserir → Tabela) salva no OneDrive Empresarial ou numa biblioteca do SharePoint.
  5. Adicione a ação Excel Online (Business) → "Adicionar uma linha numa tabela", apontando pra essa planilha e tabela.
  6. Mapeie os campos dinâmicos recebidos (nome, telefone, dataReuniao, motivo, status, tipo, etc.) para as colunas da tabela.
  7. Salve o fluxo. Copie a URL da solicitação HTTP POST gerada (fica em "Quando uma solicitação HTTP for recebida").

2 Cole aqui a URL do fluxo (Power Automate)

Essa URL fica salva apenas neste navegador (não é compartilhada com a Anthropic nem com terceiros). Quem tiver essa URL consegue enviar dados pro seu fluxo — trate-a como uma senha e não a compartilhe publicamente.
